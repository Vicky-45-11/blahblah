## How I use it

1. Try an idea in a tiny file.
2. If it grows legs, move it into its own repo.
3. If it flops, leave a note about what I learned and move on.

## Daily rules

- Ship something small, even a single line.
- Write down one thing I learned.
- Keep commit messages short and clear.
